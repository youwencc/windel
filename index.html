01 · 强制删除

删不掉的文件？拖进来就完了

支持文件、文件夹批量拖放删除。自动尝试强制获取权限（takeown + icacls）、结束占用进程，仍失败时标记为重启后删除，绝不半途而废。

  • 批量拖放，多路径同时处理
  • 强制获取权限 + 结束占用进程
  • 失败自动标记，重启后彻底删除
02 · 右键菜单清理

让右键菜单回到清爽的样子

扫描全部右键菜单项，按第三方 / 系统 / 本软件分类统计。勾选即可清理，清理前自动备份，随时一键恢复。

  • 分类筛选：全部 / 第三方 / 系统 / 本软件
  • 清理前自动备份，按时间点恢复
  • 行内右键直接清理单条菜单项
